## Day 17 – San Martin Stores Analysis (Dashboard Structuring)

![](https://github.com/omolola-A/120-days-data-analytics-journey/blob/main/Day17_IMG.png)

Today was less about calculations and more about structure.

I designed the dashboard template using Excel objects — setting up the layout before placing any visuals. I’m learning that a clear structure makes the final output feel intentional rather than crowded.

After that, I went back to the analysis sheet to properly format the KPI values and pull together the metrics that will feed the dashboard charts. This part felt slower than expected. Deciding what to show — and what not to show — takes more thought than just creating measures.

The numbers are ready. The structure is ready. Now it’s about turning analysis into a clean story.

Next step: building the actual visuals and testing how everything responds to slicers and filters.
