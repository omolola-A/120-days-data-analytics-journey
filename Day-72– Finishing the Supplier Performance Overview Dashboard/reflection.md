## Day 72/120 – Finishing the Supplier Performance Overview Dashboard

After several days of working on the Supplier Performance Dashboard, I finally completed the overview dashboard today.

This project stretched me in many ways. I worked through creating DAX measures, time intelligence calculations, charts, slicers, and overall report structure. Along the way, I also learned how to create both numeric and field parameters to make the dashboard more interactive.

One part I really enjoyed was the design process. I explored building dashboard templates using both PowerPoint and Canva, and also learned how to extract color palettes directly from images to maintain consistent design aesthetics.

Not everything went smoothly though. In some parts of the guided project, the instructor used multi-row card visuals that didn’t behave properly on my end. Instead of getting stuck, I improvised by combining the new card visual with matrix visuals to recreate the same layout and formatting.

That part reminded me that building dashboards is not always about following the exact steps—it’s also about adapting when things don’t work as expected.
