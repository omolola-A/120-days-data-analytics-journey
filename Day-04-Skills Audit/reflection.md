## Day 4 – Skill Depth Audit: Knowing vs Executing

![](https://github.com/omolola-A/120-days-data-analytics-journey/blob/main/Day4-image.jpeg)


This stage of the challenge was not about building something new. It was about auditing my execution depth. I wanted to clearly separate two things I often blend together: understanding a tool conceptually and executing with independent confidence.

Below is an honest self-assessment across my core tools.

---

### Excel – 7.5/10

**Strengths:**

* Data cleaning in Excel and Power Query
* Pivot tables, summaries, and visualization
* Basic statistical analysis and sentiment analysis
* Comfortable exploring datasets independently

**Gaps Identified:**

* Lookup functions (XLOOKUP, INDEX-MATCH) are not instinctive
* Limited exposure to automation (VBA)
* Minimal use of advanced formula nesting
* Mostly use Excel in a straightforward, non-automated way

Observation: Strong functional use, limited automation depth.

---

### SQL – 6.5/10

**Strengths:**

* SELECT statements
* Joins and aggregations
* WHERE clauses and logical operators
* GROUP BY, ORDER BY
* CASE statements, aliasing
* Basic window functions
* Database and table creation/drop operations

**Gaps Identified:**

* Syntax not fully internalized (frequent note-checking)
* Limited real-world usage
* Minimal focus on query optimization and performance

Observation: Conceptual understanding is solid; execution speed and efficiency need improvement.

---

### Power BI – 8/10

**Strengths:**

* Power Query transformations
* Data modeling (primarily star schema)
* DAX measures
* Dashboard design and storytelling
* Connecting to multiple data sources (SQL, Excel, CSV, Dataverse, Web)

**Gaps Identified:**

* Complex or non-standard modeling scenarios
* Advanced DAX context manipulation
* Performance tuning
* Deployment, governance, and collaboration in Power BI Service

Observation: Strongest tool currently, but advanced modeling and service-level depth need strengthening.

---

### Python – 6.5/10

**Strengths:**

* Data wrangling with pandas and numpy
* Basic visualization with matplotlib and seaborn
* Exploratory data analysis in notebook environments

**Gaps Identified:**

* Limited structured project organization
* Minimal function writing and modular coding
* Error handling not deeply practiced
* Heavy reliance on reference examples
* Limited experience with large datasets

Observation: Functional but still in an exploratory phase.

---

## Key Realization

Across tools, I generally understand the concepts. However, consistent repetition and real-world application are what build execution depth. In some areas, I am operating at a “guided confidence” level rather than independent mastery.

---

## Next Step

Select one weak area and practice it deliberately over the next few days, focusing on repetition and independent execution rather than adding new tools.
