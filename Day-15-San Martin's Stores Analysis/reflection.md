## Day 15 – First Unguided Project (San Martin’s Stores Analysis)

![](https://github.com/omolola-A/120-days-data-analytics-journey/blob/main/Day-15.png)

Today I moved from guided learning to building on my own.

I picked the San Martin’s Stores dataset with the goal of creating a sales overview to understand how the company is performing. Unlike the previous project that had a single dataset sheet, this one came with 7 different tables. My first challenge was figuring out how to clean and connect them properly.

I used Power Query to clean the data and assign the correct data types before loading everything into tables. From there, I built Pivot Tables and calculated the main KPIs: Sales, Orders, Profit, and Quantity Sold. I also created a date table to support time-based analysis.

That’s where things got tricky.

All the orders were placed within a single month. That means no Year-over-Year or Month-over-Month comparisons. The time intelligence approach I practiced earlier doesn’t apply directly here.

Now I’m exploring whether Week-over-Week analysis within the month makes more sense.

This project feels different. Less step-by-step guidance. More decisions to make. More moments of uncertainty.

And honestly, that’s where the real learning is happening.
