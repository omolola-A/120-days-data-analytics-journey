## Day 31/120 – Cleaning and Transforming the Data

![](https://github.com/omolola-A/120-days-data-analytics-journey/blob/main/Day-31.png)

Today’s focus was on preparing the data while constantly referring back to the business request, the business demand overview, and the user stories from the previous step.

Before writing transformation queries, I spent some time understanding the structure of the dataset. I looked at the difference between fact tables and dimension tables, then identified which tables were actually necessary based on the user stories and reporting needs.

From there, I moved into data cleansing and transformation using SQL. The goal wasn’t just to clean the data randomly, but to shape it in a way that supports the questions the business wants answered.

One small but useful discovery today was learning about SQL code beautifiers (formatters). After seeing how they help structure messy queries into something easier to read, I tried it out while working in MySQL. It made the queries much clearer to review.

It’s interesting how much of analytics work happens before any dashboard is built.

Next step: continue shaping the data so it’s ready for analysis and reporting.
